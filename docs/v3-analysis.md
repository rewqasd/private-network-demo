# V3 问题分析报告（V4.0 设计依据）

> 分析对象：`v3.2-final` 标签（commit `fe5960a`，2026-07-23），线上地址 `https://rewqasd.github.io/private-network-demo/?v=20260723-3`。
> 分析方法：读取源码（`index.html` 208 KB 单文件：CSS 约 4.1 万字符、JS 约 16.5 万字符，25 个 `<svg>`、18 个 `@keyframes`）；用 Playwright + Chrome 157 在 1920×1080、1366×768、390×844 实测截图；运行原测试脚本 `private_network_demo_v3_test.js`（15 个用例 + 1 个交互用例全部通过）。

## 1. 页面结构与产品分类

| 维度 | V3 现状 |
| --- | --- |
| 结构 | 单 HTML，左侧 19 个平铺导航卡片 + 右侧单页主体；`?page=N`、`?mission=` 深链 |
| 产品分类 | 无分类层级：家宽 PPPoE、DIA、互联网安全专线、SDH/MSTP、OTN 精品专线、智能 OTN、云联网、云联网优势 8 个“产品页”与医院、四川政务/政法/金融、制造集团 5 个“行业页”、6 个“工具页”（选择地图、问题诊断、硬件地图、大白纸、闯关、总览）混排 |
| 产品命名 | 多为简称（“OTN 精品专线”“智能 OTN”），未体现正式产品体系：政企精品网 =（金融精品网、智能 OTN、普通 OTN）；互联网安全专线焕新后的五类安全服务未出现 |
| 数据组织 | `pages` 数组写在 JS 内，SVG 由 `svgPPPoE()`、`svgDIA()` 等 20 余个函数手写拼接字符串；内容与渲染强耦合，新增产品需改代码 |

## 2. 实测发现的问题

### 2.1 SVG 与网络逻辑
1. **连线压住文字**：选择地图（P14）中央“我要一条专线”被 7 条彩色虚线穿过；政务页（P10）“川东北市州”“核心链路灾备”“安全专线/WAF”等标签被线条或云形遮挡、相互重叠。
2. **首屏画布半空**：DIA 页（P2）首屏右半区“DIA / 互联网专线”一侧为空，只有左侧家宽示意，核心对比没出现。
3. **颜色无业务语义**：红、橙、紫、绿、青虚线大量并用，颜色与“正常/攻击/备份/硬管道”等状态没有固定对应，学员无法据色读图。
4. **网络节点不完整**：DIA 页没有出现 OLT/BRAS/城域网/骨干网等接入链路关键节点；安全专线页没有表达“近源清洗、原路回注”；OTN 页没有 1+1 保护倒换、硬管道隔离的过程。
5. **动画单一**：18 个 keyframes 以虚线流动、脉冲为主（无 SMIL / 路径粒子），动画只是“在动”，不表达先后因果。

### 2.2 讲师控制与交互
1. 只有“重播动画”“讲师提示”“播放总览”三个按钮，**没有上一步/下一步、暂停、速度、节点点击说明、路径高亮**，讲师无法按讲课节奏逐步揭示。
2. 讲解内容（对比、场景、边界、结论）放在首屏以下，需要滚动才能看到，投影时打断讲解。
3. 闯关、大白纸是很好的课堂设计，但答案逻辑与产品数据没有关联。

### 2.3 视觉与适配
1. 深蓝底 + 玻璃拟态 + 渐变发光，投影到会议室幕布时对比度下降，红/青细线容易糊。
2. 1920×1080 下左侧导航占 300 px 且 19 项需滚动；页面信息密度不均（SVG 下方大面积空白）。
3. **390×844 手机端**：导航卡片占满首屏，SVG 被等比缩到约 350 px 宽，字号缩到不足 6 px，不可读。

### 2.4 内容准确性
1. 页面内容以通用说法为主（如“可叠加防火墙、抗 DDoS、VPN、上网行为管理”），缺少资料中的正式指标：政企精品网 99.999% 可用率、50 ms 保护倒换、2M~100G、1 ms 时延圈；智能升速颗粒度；安全专线五类规格等均未出现。
2. README 列了 11 份资料，但页面没有逐条标注出处，无法核验。
3. 行业页（四川政务/政法/金融、制造集团、三甲医院）属于教学抽象场景，页面未区分“教学场景”与“正式案例”。

## 3. 值得保留的内容

| 保留项 | V4 去向 |
| --- | --- |
| 提问式讲解（先问 / 追问 / 判断） | 每个演示步骤配“讲师提示”与课堂提问 |
| “公共道路 vs 专属车道”等教学比喻 | 讲师提示中保留，并与正式参数并列 |
| 产品选择地图（客户说“我要一条专线”） | 重做为“需求→产品”决策树（营销实战） |
| 问题诊断（痛点→判断条件→商机信号） | 营销实战“需求识别 / 商机识别” |
| 客户侧硬件地图 | 网络技术中心“客户侧设备与分界点” |
| 四行业闯关、大白纸方案题 | 课堂互动（题库化、可计分） |
| `?page=N`、`?mission=` 深链 | V3 原样归档到 `/v3/`，旧链接自动跳转，保证历史可访问 |

## 4. V4 设计结论

1. **数据与展示分离**：产品、参数、对比、场景、拓扑、题库全部进入 `data/*.json`，每个参数带出处（文件名 + 页码）。
2. **拓扑引擎化**：用统一的拓扑描述（区域、节点、链路、流量、步骤）驱动 SVG 渲染与动画，节点卡片绘制在连线之上，彻底避免压字。
3. **语义配色**：联通红为品牌主色；数据流蓝/青、安全橙、正常绿、故障红、普通连接灰，全站固定含义并附图例。
4. **讲师优先**：分步播放（上一步/下一步/暂停/重播/速度）、节点点击说明、路径高亮、讲师模式、全屏、快捷键。
5. **浅色商务画布**：适合投影；1920/1600/1366 三档桌面布局 + 平板/手机降级布局（拓扑区可横向滑动、文字不缩到不可读）。
